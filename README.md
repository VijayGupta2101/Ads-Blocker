# Ads Blocker

## Overview

Ads Blocker is a lightweight browser extension designed to block unwanted advertisements and improve the overall browsing experience. It helps reduce distractions, creates a cleaner interface, and enhances browsing performance by limiting unnecessary ad content.

## Features

- Blocks unwanted advertisements
- Improves browsing experience
- Reduces distractions while browsing
- Lightweight and easy to use
- Helps create a cleaner webpage interface

## Technologies Used

- JavaScript
- HTML
- CSS
- Chrome Extension APIs

## Installation

1. Clone this repository:

```bash
git clone https://github.com/your-username/Ads-Blocker.git
Open your browser and go to the extensions page.
Enable Developer Mode.
Click on Load Unpacked.
Select the project folder.
The extension will now be added to your browser.
Usage

Once installed, the extension works in the background to block unwanted advertisements and improve browsing quality.
